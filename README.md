## 🌟 核心特性

1. **📝 页面级简历快速填报**
   - 采用 **Shadow DOM** 技术封装侧边栏，与任意招聘网站 CSS **100% 隔离**，绝无样式冲突。
   - 屏幕右侧常驻吸边胶囊按钮，支持 `Ctrl+Shift+F` 快捷键一键唤起/收起。
   - 监听光标聚焦，点击任意字段（手机、邮箱、多段教育/实习/项目经历）自动触发原生 Setter 与 `input/change` 事件设值，并带有剪贴板自动写入兜底。
2. **📌 岗位一键智能收录**
   - 侧栏顶部一键扫描当前招聘页面（支持 JSON-LD 结构化数据、OpenGraph 元标签与正文正则提取）。
   - 智能识别公司名称、投递岗位、目标城市、当前阶段与投递日期。
   - 提供轻量抽屉微调表单，核对后一键存入本地投递记录。
3. **📊 内嵌全功能管理中枢 (Dashboard)**
   - 点击浏览器右上角插件图标或网页侧栏底部按钮，一键全屏打开管理中枢。
   - **投递追踪看板**：阶段漏斗、状态统计（总投递/今日投递/进行中/Offer数）、高级搜索与排序、一键推进招聘阶段、日程待办提醒。
   - **我的简历资料库**：全可视化表单编辑器，自由维护个人字段与多段经历（支持增删、排序、自定义属性），修改后**实时同步给所有网页端侧边栏**。
   - **数据安全与备份**：100% 离线本地存储（`chrome.storage.local`），支持 JSON 完整备份导入导出（无缝向下兼容旧版备份文件），支持 IndexedDB 历史版本快照回退。
4. **🖼️ 离线 OCR 截图智能识别**
   - 内置离线 Tesseract 中文识别引擎，支持将微信、邮件或网申成功截图拖入，自动识别并建档。
5. **简历内容网申界面一键填充**
   - 网申侧边栏，点击一键填充即可，功能不完善，注意逐条核对。

## 🆕 二次开发新增功能

### 📚 多版本简历管理（Multi-Version Resume）

**解决什么问题**：原版简历资料库只存一份数据，导入新简历会直接覆盖旧的。但秋招时同一个人往往需要维护多份简历（如：投国企/央企用含体制内经历的版本，投私企用另一版），反复导入导出极易出错——尤其在严格区分经历的场景下，误填内容后果严重。

**实现方案**（低侵入）：`content.js` 始终只读取固定的 `resume.v1` 存储位，因此**切换版本时将该版本内容写入 `resume.v1` 即可，`content.js` 零改动**，风险最低。

**功能**：

| 能力 | 说明 |
|---|---|
| 版本切换 | 简历资料库顶部下拉框，一键切换当前生效的简历版本 |
| 新建版本 | 以当前简历为副本创建新版本，或直接导入新 JSON |
| 删除版本 | 删除当前选中版本（至少保留一个） |
| 自动同步 | 保存/导入时自动回写到当前版本，切换后实时同步到所有网页侧边栏 |

**存储结构**：新增 `autumnRecruitmentTracker.resumeVersions.v1`，向下兼容旧版备份文件。

## 🛠️ 安装与使用步骤

### 1. 安装扩展
1. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 并回车；
2. 在右上角开启 **“开发者模式”**（Developer mode）；
3. 点击左上角的 **“加载已解压的扩展程序”**（Load unpacked）；
4. 选择工作区目录下的 `autumn-job-assistant-tracker` 文件夹即可完成安装。

### 2. 开始使用
- **网申填表**：在招聘网站页面点击右侧 `📝 简历助手` 胶囊（或按 `Ctrl+Shift+F`），光标选中输入框后点击对应字段即可自动填入；
- **岗位收录**：网申完成后点击侧栏顶部的 `📌 一键收录当前岗位`，核对后保存；
- **查看看板与配置简历**：点击浏览器右上角扩展图标，或点击侧栏底部的 `📊 投递看板` / `⚙️ 简历配置` 即可直达管理中枢。
